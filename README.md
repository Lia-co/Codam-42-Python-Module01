# DESCRIPTION
This is the second Python module in 42 core curriculum. Students tackle more complex programming challenges by creating a comprehensive garden data management system.
The function must be written in Python 3.10+, and follows the flake8 linter standards.

Students work on:
- Understanding how Python programs are structured and executed
- Organizing data using an object-oriented approach
- Creating reusable code components
- Building systems that can adapt and extend
- Protecting data integrity in collaborative environments
- Designing scalable software architectures

After finishing this module, differences between function and program, differrent data types, if condition usage, recursion and type hints should be well understood by students.
